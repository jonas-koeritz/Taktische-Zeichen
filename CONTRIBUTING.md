# Neue Zeichen

Verwende am besten ein bestehendes, ähnliches Zeichen als Grundlage um das neue Zeichen zu erstellen. Auf diesem Weg ist eine Deckungsgleichheit gegeben.
Symbole, Grafiken und sonstige Inhalte sollten nach Möglichkeit per Hand aus SVG-Primitiven zusammengestellt werden. So entsteht menschenlesbarer, aufgeräumter Code. Lange Pfaddefinitionen, komplexe Transforms und ähnliche wenig offensichtliche Elemente sind zu vermeiden. Dies trägt auch zur Kompatibilität bei.
Eine Ausnahme bildet die Definition der Schriftart, bis zu einer besseren Lösung muss diese leider so komplex eingebettet bleiben.

# Korrekturen

Korrekturen sind gerne gesehen, bei der Menge an Dateien kann es passieren dass sich kleine Fehler einschleichen. Ein guter erster Beitrag!

# AI Policy

Der Code in diesem Repository ist zu 100% von Menschen mit Hilfe von Open Source Software erstellt. Bei der Entwicklung wurde keine "KI", "Large Language Models" oder ähnliche Technologie verwendet.

Code der mit Hilfe von LLMs, "vibe-coded" oder mit ähnlichen Methoden erstellt wurde wird nicht akzeptiert. Nutzer die versuchen solchen Code als eigene Arbeit zu maskieren werden von der Mitarbeit an diesem Projekt ausgeschlossen.
